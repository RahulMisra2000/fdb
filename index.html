Prices and news are pulled first from Yahoo Finance's unofficial data feed (routed through a public CORS proxy, since Yahoo has no official API), falling back to Finnhub if you've added a key and Yahoo is unreachable. If neither can price a real holding, it's shown as missing (a red "NO DATA" tag and a banner up top) rather than guessed — you can also enter a price manually for anything no free source will cover (e.g. mutual funds). The only automatic placeholder values are for the four illustrative demo tickers (AAPL/MSFT/NVDA/SPY) used when no data source is configured at all. The small badge next to each price (Y / F / D / M / CASH) shows which source served that row. Because the Yahoo path is unofficial and proxy-dependent, treat it as best-effort rather than guaranteed uptime. CSV import reads Symbol, Quantity, Description, and Cost Basis from a brokerage position export — tested against Fidelity's and Schwab's formats (different column names and account layouts are handled automatically); other brokers with similarly-shaped exports will likely work too. Money-market/cash-sweep rows and positions split across multiple accounts for the same symbol are combined into one row. Today's/Total gain-loss columns from the file are snapshots at export time, so they aren't imported as-is — instead, Unrealized Gain/Loss is recomputed live from your cost basis against the current fetched price every refresh. The "signal" shown per holding is a rules-based read of momentum and 52-week range — it is generated automatically, is not investment advice, and is not a prediction of future performance. Always confirm figures with your broker or a licensed advisor before acting.
